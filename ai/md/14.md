# 14 · 镜头语言与运镜体系（Camera Language）

> 知识截止 2026-09。本篇补 `12_分镜表实操与模板.md` 缺的**设计法**：`12` 讲「表怎么填」，本篇讲「**为什么这么填**」。
> 带 ⭐ 的段落是本库特有（AI 生成场景下的镜头语言差异），真人剧组资料里没有。

---

## 一、一镜四个变量（先记住这张总表）

**一镜 = 四个决定**：看多大（景别）、谁强谁弱（机位角度）、看哪里（构图）、看得怎么动（运镜）。

| 变量 | 决定什么 | 分镜表字段 | 详见 |
|---|---|---|---|
| 景别 | 信息量与情绪距离 | `景别` | 第二节 |
| 机位角度 | 权力关系与心理 | （合写在「画面内容」或提示词） | 第三节 |
| 构图 | 视线引导与空间感 | （写在「生图提示词」） | 第四节 |
| 运镜 | 节奏与情绪流动 | `运镜` | 第五节 |

**AI 提示词里的位置**（对应 `13` 篇 2.5 的固定结构）：景别与角度在「构图 / 景别」位，构图词在「光影氛围」前，运镜另起（生视频阶段才注入，见 `13` 4.4）。

## 二、景别：不是名词表，是选择逻辑

| 景别 | 画面范围 | 叙事功能 | 什么时候用 | ⭐AI 生成风险 |
|---|---|---|---|---|
| 大远景 | 环境为主，人极小 | 交代时空、渺小感 | 开场、转场、史诗感 | 人脸糊成一团，**别用来推情绪** |
| 远景 | 人物全身 + 环境 | 空间关系、孤独、走位 | 场面交代、人物境地 | 细节丢失，特征词失效（易跳脸） |
| 全景 | 人物全身为主 | 动作完整、人与人距离 | 打斗、走位、关系戏 | 手部动作易畸变 |
| 中景 | 腰部以上 | **信息与情绪的平衡点** | 对话主力、叙事主力 | **最稳**，默认选它 |
| 中近景 | 胸部以上 | 情绪开始主导 | 竖屏对话主力、口型镜 | 较稳，⭐竖屏最佳 |
| 近景 | 肩部以上 / 头部 | 情绪交流、细微表情 | 内心戏、关键台词 | 五官开始不稳 |
| 特写 | 脸部 / 局部 | 情绪爆点、道具强调 | 爽点反应、钩子、悬念 | 易鬼手、脸崩 → 用 PuLID 精修（见 `12` 二） |
| 大特写 | 眼睛 / 嘴 / 手 | 极强冲击、心理放大 | 慎用，一集 1–2 次 | 极易崩，强烈建议改用近景 |

### 景别节奏三律

1. **递进律（情绪靠景别收紧）**：情绪升级时，景别逐级收紧 —— `远景 → 中景 → 近景 → 特写`。观众的情绪距离跟着缩短，不需要台词解释。
   反例：一上来就大特写，观众还没建立"这是谁在哪"，情绪无根。
2. **对比律（同景别硬切必跳）**：相邻两镜景别**要么差 ≥1 级，要么差很多**（远跳特）。**同级相连 = 跳切感**（剪过的画面"顿"一下）。
3. **呼吸律（防审美疲劳）**：连续 3 个以上特写/近景会让人"憋"，中间必须插一个中景或远景**透气**。

### ⭐ 竖屏漫剧的"主力景别"与真人剧不同

- 真人竖屏短剧爱用大特写（有真人脸的真实感兜底）。
- **AI 竖屏漫剧的默认主力是「中近景」**：既保住脸部一致性（特征词还有效），又比中景有情绪。
- 结论：整集景别分布建议 **中近景 40% / 中景 25% / 近景 20% / 远景与全景 10% / 特写 5%**。特写留给"必须爆"的那一两镜。

## 三、机位与角度：那是"权力关系"

| 角度 | 英文写法 | 心理含义 | 典型用法 |
|---|---|---|---|
| 平视 | `eye-level shot` | 平等、客观、默认 | 大部分叙事镜 |
| 仰视 | `low angle, looking up` | 强势、压迫、崇高 | 反派登场、主角觉醒、宣告 |
| 俯视 | `high angle, looking down` | 弱势、被审判、可怜 | 主角受辱、被包围、孤立 |
| 过肩 | `over-the-shoulder shot` | 观众代入对话一方 | 对话戏主力（配正反打） |
| 斜角 | `dutch angle, tilted camera` | 失衡、不安、失控 | 悬疑、精神崩坏 |
| 背面 | `seen from behind` | 神秘、保持距离 | 角色决意、离场 |
| 正脸 | `frontal, facing camera` | 坦诚、压迫（打破第四墙） | 高潮独白、直视镜头 |

**同一个人，角度一换，观众立场就换**：主角受辱用俯拍、反击用仰拍——**"由俯转仰"本身就是一段戏**（见 `15_导演思维与场面调度.md` 的情绪对照表）。

### ⚠️ 轴线原则（AI 最常错、观众最能感觉到的一处）

两个角色之间有一条**假想连线（关系轴 / 180° 线）**。**所有镜头必须留在轴的同一侧**——否则观众会觉得"两人忽然换了位置""怎么都朝同一边看"。

- **对话戏标准做法（正反打）**：A 在左、看向右；B 在右、看向左。切来切去都在同一侧。
- **越轴（跳轴）的三种补救**：
  1. 插入一个**中性镜**（正对轴线，如两人侧面全景）；
  2. 用一个**移动镜头**当着观众的面越过去（观众看得见就没问题）；
  3. 插一个**空镜/环境镜**当缓冲。
- ⭐ **AI 特有坑**：即梦 / H3 不知道你在哪一侧，**必须显式写视线方向**，否则两人极容易都朝同一边看、变成"隔空对视失败"。

```
正确示例（生图提示词）：
two people facing each other in a corridor, A on the left side looking right,
B on the right side looking left, over-the-shoulder composition
```
> 记住一句话：**轴不是物理规律，是观众的方位感。** 破坏它，观众说不出哪里错，但会"觉得怪"。

## 四、构图：让画面替你说台词

| 构图法 | 英文写法 | 作用 | 什么时候用 |
|---|---|---|---|
| 三分法 | `rule of thirds` | 代入感、画面不呆 | 通用默认 |
| 中心对称 | `centered composition, symmetrical` | 庄重、压抑、仪式感 | 权谋、审判、宗教感 |
| 视线空间 | `leading space in the direction of gaze` | 人物看哪，哪边留空 | 对话、期待、凝望 |
| 头顶留白 | `appropriate headroom` | 别切头顶（切了显廉价） | 所有有人脸的镜 |
| 引导线 | `leading lines` | 把视线引到主体 | 走廊、栏杆、铁轨、窗 |
| 框架构图 | `frame within a frame` | 窥视感、被困感 | 门外偷看、窗内、帘后 |
| 前后景纵深 | `shallow depth of field, foreground bokeh` | 画面立体不外行 | 中近景 |
| 对角线 | `diagonal composition` | 动感、不稳 | 冲突、追逐 |
| 负空间 | `negative space, minimal composition` | 孤独、空落 | 失恋、失落、结尾 |
| 低位压顶 | `large negative space above subject` | 渺小、被压 | 受挫、命运感 |

⭐ **竖屏专属三条规矩**：
1. 写 `9:16 vertical composition`；
2. 主体**居中略偏上**（下 1/3 常被字幕、平台 UI、进度条挡）；
3. 别用横向全景构图（竖屏里会变成"上下两条黑边 + 中间一条人"）。

构图词直接写英文术语最稳（模型训练语料里术语密度高）。

## 五、运镜体系：功能、情绪、稳度

| 运镜 | 英文 | 叙事功能 | 情绪 | ⭐AI 稳度 |
|---|---|---|---|---|
| 固定 | `static shot, locked-off camera` | 让观众看清、客观 | 冷静、克制 | ⭐⭐⭐⭐⭐ **最稳** |
| 推 | `slow push in, dolly in` | 逼近、聚焦、情绪升温 | 紧张、投入 | ⭐⭐⭐⭐ 慢推稳 |
| 拉 | `slow pull out, dolly out` | 抽离、揭示、孤独 | 失落、余韵 | ⭐⭐⭐⭐ |
| 摇 | `pan left / pan right` | 扫视空间、跟随视线 | 探索、巡视 | ⭐⭐⭐ 慢摇稳 |
| 升降 | `crane up / boom down` | 宏大、揭示全景 | 史诗、震撼 | ⭐⭐ 难 |
| 横移 | `tracking shot, truck left/right` | 陪伴、平行观察 | 客观、伴随 | ⭐⭐ 背景视差易变形 |
| 跟 | `follow shot` | 代入、紧迫 | 紧张、追逐 | ⭐ 肢体易畸变 |
| 环绕 | `orbit shot, arc around subject` | 展示、张力、高光时刻 | 燃、高光 | ⭐ **易崩（脸随角度变）** |
| 变焦 | `zoom in / zoom out` | 心理拉近（与"推"不同：不改变视角） | 突然、主观 | ⭐⭐⭐ |
| 甩 | `whip pan` | 转场、冲击 | 剧烈 | ❌ **必崩，别用** |
| 手持 | `handheld camera` | 真实、混乱 | 纪实、慌乱 | ⭐⭐ 抖动过大易闪 |

（与 `12` 二「运镜」字段、`07` 排错表「闪烁/抖动」一致：**运动幅度与可用率成反比**。）

### 运镜三律

1. **一镜只做一件事**：要么推、要么摇——**别一边推一边摇一边升降**。复合运动是 AI 崩坏的第一诱因（也违反 `12` 的"单镜 ≤5s 干一件事"）。
2. **慢优于快**：AI 视频的可用率与运动速度**成反比**。默认写"缓慢"；命中需求再提速，不要一上来就快。
3. **首镜固定**：每场第一镜、每集第一镜用**固定镜**，先把人物与空间"立住"，后续再运动。（对应 `12` 三.1「首次用固定建立一致性」）

### ⭐ AI 运镜稳崩对照表（本库核心）

| 推荐主力（稳） | 谨慎（试 2–3 次取 1） | 禁用（几乎必崩） |
|---|---|---|
| 固定、缓慢推、缓慢拉、缓慢摇 | 横移、升降、跟、变焦、手持 | **快速环绕、甩镜、多轴复合、快速跟拍** |

**为什么**：视频模型是靠**帧间一致性**吃饭的。运动越大、遮挡越多、视角变化越快，误差越会累积——表现为**脸变（跳脸）、手指增生、背景融化、画面闪烁**。
> ⭐ 所以 AI 导演的核心手法是：**用「景别 + 剪辑」制造动感，而不是用「运镜」堆动感**。真人剧组里"一个长镜头环绕主角"的炫技，在 AI 里是崩坏高发区。

### 运镜提示词模板（中文 / 英文双写）

```
[速度词] + [运镜词] + [主体动作] + [稳定性词]
中文：镜头缓慢推近，少女缓缓回头，画面流畅稳定
英文：slow push in, girl slowly turning her head, smooth stable camera, no camera shake
```

- **速度词表**：缓慢 / 极慢 = `slowly / gently / subtly / slightly`；匀速 = `steady`；快速 = `fast / rapid`（⚠️ 不推荐）。
- **稳定性词表**（几乎必加）：`smooth, stable, steady camera, constant velocity, no camera shake, no jitter`。
- ⚠️ **正向里别写否定词**：`no camera shake` 属于稳定性术语，可直接用；但"不要水印 / 不要文字"这类**必须进 negative 字段**（硬规见 `12` 三.7、`07` 三末）。

### 运镜幅度要与时长匹配

| 时长 | 能做什么 | 说明 |
|---|---|---|
| 2s | 只够固定 + 微动（呼吸/发丝） | 做"推"会**无感**（位移太小看不出），浪费 |
| 3–4s | 缓推 / 缓摇一段 | 主力区间 |
| 5s | 缓推到位 / 缓摇 90° | 上限（`12`：单镜 ≤5s 是黄金线） |
| >5s | **拆镜** | 别硬拉，必闪 |

## 六、镜头组接（剪辑语法）

**分镜表只解决"单镜怎么拍"，组接解决"两镜能不能接"。**

### 能接 / 会跳

| 能接（顺） | 会跳（顿 / 乱） |
|---|---|
| 景别差 ≥1 级 | 同景别 + 同机位（跳切感） |
| 有视线因果（他看她 → 她所见） | 越轴（方位感翻转） |
| 同一空间、同一轴侧 | 运动方向相反（左进接右进） |
| **动接动**（运动方向一致、速度接近） | 光影/色温突变 |
| 静接静 | 主体大小突变但景别没变 |

### 几种具体手法

- **匹配剪辑（match cut）**：形状匹配（圆月 → 圆盘）、动作匹配（抬手 → 落手）、声音匹配（关门声 → 下一场开门声）。**最自然的转场**，比"淡入淡出"高级。
- **30 度原则**：同一主体的相邻两镜，机位角度变化要 **>30°**；否则像"画面跳了一下"。
- **跳切（jump cut）**：故意的时间压缩（同一机位切掉中间段）。漫剧里容易显**廉价/像失误**，慎用；用"拆不同景别"替代。
- **遮挡转场**：用前景物体（人或物）划过镜头当剪辑点。⭐ **AI 最友好**——写 `foreground object passing close to camera` 生成一段，划过瞬间就是天然剪辑点。
- **动静相接**：动 → 静 = 句号；静 → 动 = 启动。收尾镜用静、开场镜用静，中间用动。
- **空镜（insert shot）**：雨、灯、钟、手、门——**给观众喘气、也给节奏换挡**。每 20–30 秒插 1 个空镜，同时它还是"一致性保险"（不用脸，绝对不崩）。

> 与 `06_后期包装与平台适配.md`（转场）分工：`06` 讲**用什么转场特效**，本篇讲**为什么这两镜能接**。

## 七、给 AI 的用法

- 用户给剧情梗概时，AI 应**按"景别递进 + 角度表意 + 单一运镜"设计镜头序列**，并在分镜表的「景别」「运镜」两列填**具体值**（不能留空、不能全填固定）。
- **运镜保守优先**：先只从「固定 / 缓慢推 / 缓慢拉 / 缓慢摇」四选一；用户明确要动感时再考虑其他，并主动提示崩坏风险。
- **必须显式写视线方向与轴侧**（`A on the left looking right`），防对视错乱。
- **竖屏默认**：中近景为主 + 主体居中略偏上 + 下部留白避字幕 + 写 `9:16`。
- **一致性优先**：每场第一镜固定；整集景别分布按 `中近景 40% / 中景 25% / 近景 20% / 远全 10% / 特写 5%` 规划。
- 设计镜头时**同时检查组接**：相邻两镜景别是否差 ≥1 级、是否同轴侧、运动方向是否一致。

## 八、自检清单（设计完镜头序列后逐条过）

- [ ] 前 3 镜里有钩子镜？（特写/冲突/意外）
- [ ] 景别是否**有递进**（不是全中景平铺）？
- [ ] 相邻镜景别是否**差 ≥1 级**（没出现同景别硬切）？
- [ ] 是否**有远景/空镜透气**（没连续 3 个以上特写）？
- [ ] 人物权力关系是否用**角度**表达了（俯拍弱势 / 仰拍强势）？
- [ ] **轴侧是否一致**、视线方向是否写明？
- [ ] 每镜是否**只有一个运镜**？
- [ ] 运镜是否都在「稳」档（有无误用环绕/甩镜）？
- [ ] 运镜幅度是否**与时长匹配**（2s 别做推）？
- [ ] 特写数量是否 ≤5%（留给必须爆的那几镜）？
- [ ] 竖屏构图：`9:16` + 主体居中略偏上 + 下部留白？
- [ ] 每场第一镜是否**固定**（建立一致性）？
