# 12 · 分镜表实操与模板（Storyboard Practice）

> 知识截止 2026-09。本模块是「分镜表」的**规范与实操版**（源自项目根目录的遗留辅助资料 `03_新手30天上手路线与分镜表模板.md`，本模块是其升级后的权威版）：告诉你"有哪些列、每一列怎么填才不会出事"。AI 在生成分镜或把剧本转成可生产清单时，应严格按本规范。

## 一、为什么分镜表是漫剧的"施工图纸"

漫剧是"先有图纸、再批量施工"的工业流程。没有分镜表，会出现三种典型事故：
- **跳脸**：前后镜头提示词前缀不一致，角色特征漂移。
- **接不上**：相邻镜头没标首尾帧/衔接关系，剪辑处硬切跳戏。
- **节奏崩**：单镜过长导致模型崩坏（闪烁/鬼手）或完播率掉。

分镜表 = 给"人"看的拍摄计划 + 给"AI"看的结构化指令。一个好分镜表，应能让另一位创作者或 AI 只看表就复刻出这条片子。

## 二、标准字段定义（14 列）

| 字段 | 作用 | 填写要点 |
|---|---|---|
| 镜头号 SC | 序号与剪辑顺序 | SC01、SC02…；重拍用 SC02b 不覆盖原行 |
| 景别 | 远/全/中/近/特写 | 决定显存与崩坏风险：特写易鬼手，远景易糊 |
| 时长(s) | 该镜头持续秒数 | **单镜 ≤5s** 是黄金线，动作戏 ≤3s，口播可 8–12s |
| 画面内容 | 这一镜发生什么 | 动词开头："主角推门""刀光闪过"，忌形容词堆砌 |
| 运镜 | 推/拉/摇/移/固定/环绕 | 固定最稳；环绕最易闪；首次用固定建立一致性 |
| 台词/旁白 | 该镜配音文本 | **短句 ≤12 字**（中文）利于口型；长句拆镜 |
| 情绪 | 该镜情绪标签 | 紧张/甜/燃/悬疑…用于情绪曲线自检 |
| 音效 SFX | 环境/动作音 | 风声、开门、刀鸣…与 BGM 分层 |
| BGM | 配乐段 | 标注曲风与起止，避免全程同一首 |
| 生图提示词(核心) | 喂给绘图模型的词 | **全剧统一前缀 + 仅改动作**；特征词压 2–4 个；**只写正向** —— 负面词（水印/文字/畸形）另走「负面提示词」字段，严禁混入 |
| 视频模型 | Wan2.2 / 即梦 / H3… | 标清用哪种，便于排查崩坏来源 |
| 一致性方案 | IP-Adapter/PuLID/LoRA | 跨镜头锁脸手段，关键帧标注更强方案 |
| 音频文件 | v01.wav 路径 | 与台词字段对应，便于对口型 |
| 状态/备注 | 进度 + 衔接说明 | 待生成/已修脸/已配音；备注写"首尾帧接 SC01" |

## 三、填写纪律（来自踩坑经验，必须遵守）

1. **前缀统一**：全剧提示词核心前缀写死（角色名 + 风格 + 画幅），只改动作部分。例：`photorealistic, cinematic, 30s woman, jet-black bob, mole under left eye, 9:16, ` + 动作。
2. **首尾帧必填**：相邻镜头若需顺滑衔接，下游镜头必须标注"首尾帧接 SC0X"，否则硬切跳戏。
3. **单镜 ≤5s**：超出的拆成 2–3 个短镜，后期拼接。这是防闪烁/鬼手的第一原则。
4. **台词短句化**：对白按 ≤12 字切分；长独白改画外音或拆镜，否则口型必乱。
5. **景别分级规避**：大特写手部、极限表情优先避开；必须时后期修复/遮挡。
6. **状态可追溯**：每行状态用 待生成 → 生成中 → 已修脸 → 已配音 → 已合成，便于追进度与复盘。
7. **正向 / 负向严格分离（硬规，最易错）**：负面词**只能**写在独立的「负面提示词（negative）」字段，**绝不允许写进正向提示词**。原因：多数模型会把正向里的 `no xxx / 不要 xxx` **反向理解** —— `no text` 反而被当成关键词 `text` 招来乱码字，`no watermark` 反而招来水印；且否定词会稀释正向特征。**全剧共用一套负面模板，不逐镜改**（逐镜改＝负向漂移）。

**标准负面模板（可直接抄，按需删减；全剧统一一套）**
```
text, watermark, logo, signature, subtitles, username, blurry, lowres,
jpeg artifacts, worst quality, extra fingers, extra limbs, extra hands,
fused fingers, deformed hands, bad anatomy, mutated, cropped, out of frame
```
- **人物特写**追加：`extra eyes, cross-eyed, distorted face, asymmetric eyes, plastic skin, bad proportions`
- **场景 / 远景**追加：`cluttered background, distorted perspective, inconsistent lighting, duplicate objects`
- ⚠️ **平台差异**：ComfyUI / FLUX / SDXL 有独立 negative 输入框，直接用；**即梦 / Seedream / H3 等描述式接口没有该框时，不要靠 `no xxx` 硬写** —— ①优先用平台自带的「不希望出现」输入框；②没有该框就用**正向描述替代否定**（要干净背景就写 `clean simple background, plain wall`，而不是 `no clutter`）。

## 五、从分镜表到生产的字段映射

| 分镜字段 | 落实环节 / 工具 |
|---|---|
| 生图提示词 + 一致性 | 绘图：即梦 / FLUX / SDXL + IP-Adapter / PuLID |
| 视频模型 + 首尾帧 | 生视频：Wan2.2 / 即梦 / H3（FL2VA/Ref2VA） |
| 台词/旁白 + 音频文件 | 声音：GPT-SoVITS / F5-TTS / 海螺原生音 |
| 运镜 + 时长 | 剪辑：剪映 / 达芬奇，卡 BGM 点 |
| 音效 + BGM | 混音：对白优先，响度统一 |
| 情绪 | QA 自检：画情绪曲线，查是否"平" |

## 六、常见分镜病（与 `10_案例库` 反面案例对照）

| 分镜病 | 表现 | 修复（改表即可） |
|---|---|---|
| 开篇无钩子 | 前 10s 介绍背景 | 第一镜直接上冲突/悬念，背景靠动作带 |
| 单镜过长 | 15s 武打一段 | 拆成 ≤5s 短镜，后期拼 |
| 台词超长 | 独白 30 字 | 拆 ≤12 字短句或改画外音 |
| 跳脸 | 第 3 镜特征变 | 特征词压 2–4 个 + 参考图/LoRA |
| 风格漂移 | 前动漫后写实 | 全剧单一底模 + 风格锚 |
| 接不上 | 剪辑处硬跳 | 下游镜标"首尾帧接 SC0X" |

## 七、给 AI 的用法

- 用户给剧本时，AI 应**主动生成符合本节字段的分镜表**，而非只给剧情概述。
- 生成提示词时，**自动套用统一前缀模板**，避免跳脸。
- **负面词必须单独输出**：出分镜表时把负面词放在「负面提示词」字段（全剧一套），**不得混进正向提示词**；正向里禁止出现 `no… / 不要…` 类否定词。若不写该字段，默认套用本模块标准负面模板。
- 自检分镜表：检查单镜时长、台词字数、首尾帧衔接、情绪曲线，四项不过不放行。
- 本模块与 `02_剧本与叙事工程.md` 的关系：`02` 给"最小必填集（9 项）"用于让 LLM 快速拆镜，**本模块是完整生产规范（14 列）**；两者冲突时**以本模块为准**。
- 设计镜头序列时，**必须同时用 `14_镜头语言与运镜体系.md` 的规矩**：景别递进、相邻镜差 ≥1 级、单一运镜、轴侧一致、竖屏中近景为主。

## 八、分镜设计法（从剧情到镜头序列）

> 前七章解决"表怎么填"，这一章解决"**镜头从哪来**"。这是 AI 拆镜最容易跳过的一步——它会直接"把剧情逐句翻译成镜"，结果就是**全中景平铺、没有节奏、没有权力关系**。

**五步设计法**（拿到一集的剧情后，按顺序做）：

### 第 1 步：划场景（把剧情切成"场"）
一集通常 3–5 场。**场的边界 = 地点或时间或情绪目标变了**。每场只承担一个"叙事任务"（建立 / 升级 / 反转 / 收尾）。
- 好处：场是节奏的单位。**场有了，才知道 60 秒怎么分**（例：3 场 × 20 秒）。

### 第 2 步：画情绪曲线（先定情绪，再定镜头）
把这一集标成一条曲线：`压抑 → 释放 → 再压抑 → 大释放`（`02` 二.2）。
- 每个"上升点"= 一个爽点，对应**一个景别收紧 + 一个运镜靠近**（推）。
- 每个"下降点"= 喘息，对应**远景 / 空镜 / 固定镜**。
> ⚠️ 顺序不能反：**先有情绪曲线，才有镜头选择**。先堆镜头再找情绪，出来一定是"平"的。

### 第 3 步：为每场定"镜头策略"（三选一）
| 策略 | 景别 | 角度 | 运镜 | 用在哪 |
|---|---|---|---|---|
| **压迫型** | 近景为主 | 俯拍被压者 / 仰拍压迫者 | 缓慢推 | 受辱、被逼、审讯 |
| **爆发型** | 中景→特写 | 平视或略仰 | 固定（运动必崩） | 打脸、摊牌、反击 |
| **收束型** | 远景 / 空镜 | 平视 | 缓慢拉 | 结尾、余韵、留悬念 |

> ⚠️ **特写很贵**：整集特写占比建议 ≤5%，只留给"**必须爆**"的那一两镜；其余情绪用中近景解决（`14` 二「竖屏漫剧的主力景别」）。

### 第 4 步：逐镜落地（每镜只做四个决定）
> 四个决定的具体判据（景别选择逻辑、机位角度的心理含义、运镜功能与稳度）全部在 `14_镜头语言与运镜体系.md` 二～五节；**景别节奏三律（递进律 / 对比律 / 呼吸律）在 `14` 二末**。

写每一镜时依次问：
1. **景别**：这一镜要让观众看清多少？（与上一镜**差 ≥1 级**——即 `14` 二的「对比律」；情绪升级靠「递进律」收紧、连续 3 个以上近/特写要按「呼吸律」插一个远景透气）
2. **角度**：谁该显得强？（俯/仰/平）
3. **运镜**：只要一个，且优先从「固定 / 缓推 / 缓拉 / 缓摇」选。
4. **时长**：2–5s；运镜幅度要配得上时长（2s 别做推，见 `14` 五）。

### 第 5 步：查组接（成序列后再过一遍）
按 `14` 六的"能接 / 会跳"表，逐对相邻镜检查：景别差、轴侧、运动方向、光影。
- 发现问题**优先改分镜表**（换景别、换机位），不要指望后期修。

### 快速自检（设计完这一集的镜头序列）
- [ ] 场数是否 3–5 场？每场只有一个叙事任务？
- [ ] 情绪曲线是否有起伏（不是一条平线）？
- [ ] 每场是否选了明确策略（压迫/爆发/收束）？
- [ ] 相邻镜景别是否差 ≥1 级？
- [ ] 每镜是否只有一个运镜，且都在"稳"档？
- [ ] 是否每场第一镜固定、且留了空镜透气？
- [ ] 轴侧与视线方向是否写明？

> 设计完这一套，再回到「二」按 14 列填表 —— **先设计，后填表**，别边填边想。
